# Campus Connect

Campus Connect is a React Native mobile application designed to provide students with important college-related information in one place.

##  About the Project

Campus Connect helps students easily access campus updates, notices, events, and student information through a simple and user-friendly mobile application.

##  Features

-  Student Login
-  Student Registration
-  Home Screen
-  College Notices
-  Events Information
-  Student Profile
-  Logout
-  User-friendly mobile interface

## 🛠️ Technologies Used

- React Native
- JavaScript
- Expo
- React Navigation
- VS Code
- Git & GitHub

##  How to Run the Project

1. Clone the repository:

bash
git clone https://github.com/MarellaTriveni/campus-connect.git


2. Open the project folder:

bash
cd campus-connect


3. Install dependencies:

bash
npm install


4. Start the Expo development server:

bash
npx expo start


5. Open the application using Expo Go or an Android emulator.

##  Objective

The main objective of Campus Connect is to provide students with a convenient platform to access important campus information and improve communication between students and the college.
