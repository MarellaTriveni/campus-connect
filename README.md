# Campus Connect

Campus Connect is a React Native mobile application designed to help students access important college information in one place.

## About the Project

Campus Connect provides students with easy access to campus notices, events, student information, and other college-related updates.

## Features

- Student Login
- Student Registration
- Home Screen
- College Notices
- Events
- Student Profile
- Logout

## Technologies Used

- React Native
- JavaScript
- Expo
- React Navigation
- VS Code
- Git & GitHub

## Objective

The main objective of Campus Connect is to provide a simple and user-friendly mobile platform for students to access important campus information.
